# ZAC93 + ESP32 → Home Assistant

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Wiki](wiki/Home-ru.md)

Иллюстрированное руководство по локальному контроллеру Z-Wave: **Zooz ZAC93**, **ESP32-WROOM или ESP32-S3**, штатный `zwave_proxy` ESPHome и сервер Z-Wave JS.

**Физическая приёмка ещё не выполнена:** модуль заказан. Успешная сборка конфигурации не подтверждает питание, включение датчика в сеть или дальность радио. Список выполненных программных проверок и оставшихся аппаратных проверок находится в [журнале валидации](docs/validation.md).

![Архитектура](assets/diagrams/architecture.svg)

ESP32 обеспечивает сеть, ZAC93 — радио Z-Wave. ESPHome устанавливается только на ESP32; ZAC93 сохраняет заводскую прошивку Zooz. Home Assistant подключается к серверу Z-Wave JS. Отдельное добавление ESP32 через интеграцию ESPHome не добавляет датчики Z-Wave.

Для WROOM: **3V3 → контакт 1**, **GND → контакт 6**, **GPIO17 TX → контакт 8 RX**, **GPIO16 RX ← контакт 10 TX**. Для S3 используется **GPIO18 RX** вместо GPIO16. Эти записи — электрические связи; ориентацию разъёма сверять по маркировке и подробным схемам. Питание и UART ZAC93 — **3,3 В**, не 5 В/VIN. USB отключать перед соединением проводов.

![Подключение WROOM](assets/diagrams/wiring-wroom.svg)

Нужен регион ZAC93, соответствующий конечным устройствам; для североамериканских — **US/CA/MX**. Встроенная антенна уже есть. Старый Z-Wave Plus датчик не становится Long Range от смены контроллера. Ориентируйтесь на [спецификации Zooz](https://www.support.getzooz.com/kb/article/1426-zac93-gpio-module-faqs/); цена с датой в английском README не является текущим предложением.

## Что находится в репозитории

- Конфигурации [WROOM](firmware/esp32-wroom.yaml) и [S3](firmware/esp32-s3.yaml) с общим файлом настроек и закреплённым ESPHome **2026.9.1**.
- [Помощник URL](scripts/connection_url.py), который запрашивает API-ключ без отображения и правильно кодирует его для `esphome://`.
- Шесть воспроизводимых SVG; исходный [генератор](scripts/render_diagrams.py).
- Проверки документации, URL, конфигураций и публикации без секретов.
- [Wiki-страницы](wiki/Home-ru.md) как версионируемые исходники навигации. Наличие этих файлов само по себе не означает, что они уже опубликованы в отдельной GitHub Wiki.

[Описание четырёх offline-инструментов](docs/community-tools.md) связывает этот проект с проверкой миграций сущностей, смысла измерений, синтетических сценариев HA и записанных голосовых испытаний. Они работают с предоставленными данными и не подтверждают аппаратную исправность ZAC93.

## Вклад и приватность

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_docs.py
python3 scripts/render_diagrams.py
git diff --exit-code -- assets/diagrams
```

Для проверки конфигураций установить [requirements.txt](requirements.txt) и выполнить `python3 scripts/validate_configs.py`; этот скрипт использует временные фиктивные секреты. Не публиковать реальные API-ключи, Wi-Fi-пароли, OTA-пароли, Z-Wave security keys, DSK, приватные адреса, резервные копии и прошивки с личной конфигурацией.
