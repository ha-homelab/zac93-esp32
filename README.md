# ZAC93 + ESP32 → Home Assistant

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Wiki source](wiki/Home.md)

An illustrated build guide for a local Z-Wave controller using a **Zooz ZAC93**, an **ESP32-WROOM or ESP32-S3**, ESPHome's native Z-Wave proxy, and Z-Wave JS.

**Build status:** hardware ordered; physical commissioning is pending. This repository provides wiring references, firmware configurations and a commissioning procedure. See the [validation record](docs/validation.md) for what has actually been tested.

![System architecture](assets/diagrams/architecture.svg)

The ESP32 supplies the network connection. The ZAC93 supplies the Z-Wave radio and retains its Zooz firmware. Home Assistant talks to a Z-Wave JS server. Adding the ESP32 to the ESPHome integration alone does not add the Z-Wave devices.

## Browser installation

**[Open the USB installer](https://ha-homelab.github.io/zac93-esp32/)** for the WROOM 4 MB or S3 N8 8 MB reference board. Connect by USB, install the onboarding image and enter Wi-Fi in the browser. Then adopt it in ESPHome Device Builder and install its per-device encrypted application before connecting the ZAC93. [Complete browser guide and troubleshooting](docs/browser-install.md).

## Four connections

For the **WROOM** reference build: ESP32 **3V3 → ZAC93 pin 1**, **GND → pin 6**, **GPIO17 TX → pin 8 RX**, **GPIO16 RX ← pin 10 TX**. The **S3** reference build uses **GPIO18 RX** instead of GPIO16. Identify pins by signals and the board markings, not by the apparent orientation of a photograph.

![WROOM wiring](assets/diagrams/wiring-wroom.svg)

**ZAC93 power and UART logic are 3.3 V. Do not connect its supply to 5 V/VIN.** Disconnect USB before wiring. The diagrams are electrical maps, not mechanical templates for every ESP32 board.

## What to buy

- [Zooz ZAC93 LR](https://www.thesmartesthouse.com/products/zooz-800-series-z-wave-long-range-gpio-module-zac93-lr), **US/CA/MX** version for North American devices. Listed at **US$17.95 on 2026-10-14**, excluding the ESP32, accessories, delivery and taxes. Prices can change.
- Either an ESP32 DevKit with an **ESP32-WROOM-32/32D/32E**, or the reference **ESP32-S3-DevKitC-1 N8** board. Other boards need their pinout and flash size checked.
- Four short insulated jumper wires with connectors that fit the actual headers, a USB data cable, adequate USB power, and a nonconductive mount or enclosure. A multimeter is useful for commissioning.

The ZAC93 has an onboard antenna; an external antenna is not required. The US classic Z-Wave region is commonly described as **908.42 MHz**. This is not a statement that every Long Range channel uses that frequency. Match the controller and end-device regions; a Z-Wave LR controller does not turn older sensors into LR devices. See [Zooz's specifications and FAQ](https://www.support.getzooz.com/kb/article/1426-zac93-gpio-module-faqs/).

## Software supplied here

- [WROOM configuration](firmware/esp32-wroom.yaml) and [S3 configuration](firmware/esp32-s3.yaml), sharing [common settings](firmware/common.yaml).
- ESPHome **2026.10.0**, pinned in [requirements.txt](requirements.txt), with native `zwave_proxy`, encrypted API and mandatory encrypted OTA using the same device PSK.
- A [connection URL helper](scripts/connection_url.py) that correctly encodes the API key.
- Six original SVG diagrams, generated by [a reproducible script](scripts/render_diagrams.py).
- Automated configuration, URL-helper and documentation checks. Public USB onboarding images contain no credentials or Z-Wave controller. Your adopted application image and controller backups remain private.

Z-Wave JS documents the native [`esphome://` transport](https://github.com/zwave-js/zwave-js/blob/master/docs/usage/esphome-connection.md). It handles timing-sensitive serial acknowledgements on the ESP32, avoiding a raw serial-over-Wi-Fi round trip for every acknowledgement. The configurations use the official [ESPHome Z-Wave proxy component](https://esphome.io/components/zwave_proxy/).
