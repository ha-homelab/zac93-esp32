# Подключение и первое включение в сеть

[Главная](Home-ru.md) · [English](Connection.md) · [Диагностика](Troubleshooting-ru.md)

Начните с [полной русской инструкции](../docs/guide-ru.md) и [фотографий/схем](../docs/hardware.md). Явно выберите WROOM или S3. Перед соединением проводов отключите питание, сверьте маркировку сигналов и питание/логику 3,3 В. Используйте существующий YAML выбранной платы; эта страница не вводит новую распиновку.

1. [Установите ESPHome на ESP32](../docs/firmware.md). ZAC93 сохраняет свою прошивку, личные секреты остаются вне публикации.
2. [Соедините Z-Wave JS UI с ESPHome proxy, а HA — с WS Server](../docs/home-assistant.md). Это разные соединения с разными портами. Только один Z-Wave-драйвер должен владеть контроллером.
3. Выполните inclusion по инструкции датчика, завершите interview и подтвердите реальный отчёт датчика. Одного статуса API connected недостаточно.
4. Заполните [список приёмки](../docs/commissioning.md), сохраните версии, наблюдения и незавершённые проверки приватно. До миграций и обновлений сохраните NVM и ключи сети.

Скриншоты в подробной инструкции — подписанные внешние примеры. Они не подтверждают физическую приёмку этого проекта. Актуальное разделение выполненных и ожидаемых проверок находится в [журнале валидации](../docs/validation.md).
