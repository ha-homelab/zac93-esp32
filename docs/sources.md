## Hardware sources

- [Zooz ZAC93 product](https://www.thesmartesthouse.com/products/zooz-800-series-z-wave-long-range-gpio-module-zac93-lr): regional variant, listed price and hardware overview.
- [Zooz ZAC93 manual](https://www.getzooz.com/downloads/zooz-z-wave-800-series-long-range-gpio-module-zac93-LR-manual.pdf): power and intended controller use.
- [Zooz installation guide](https://www.support.getzooz.com/kb/article/1215-zac93-800-gpio-module-installation-guide/): board installation reference.
- [Zooz FAQ](https://www.support.getzooz.com/kb/article/1426-zac93-gpio-module-faqs/): antenna, buttons and supported use.
- [Zooz change log](https://www.support.getzooz.com/kb/article/1389-zac93-gpio-module-change-log/): hardware v2 reset connection and firmware history.
- [Espressif ESP32-DevKitC](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html): WROOM/WROVER pin availability and power choices.
- [Espressif ESP32-S3-DevKitC-1 v1.1](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html): S3 pins, module variants and USB ports.
- [peterxian's original ZAC93/ESP32 build](https://community.home-assistant.io/t/make-a-z-wave-to-wifi-bridge-with-esphome-stream-server-and-zooz-zac93-gpio/565913): first-hand four-wire assembly, readable module silkscreen, UART rate and connection photos. Its ESP32 pins and raw TCP software differ from this project's design.

## Visual provenance

The six SVGs in `assets/diagrams/` are **original illustrations** generated by `scripts/render_diagrams.py`. They show the electrical connections and software flow specified by this repository. They are not photographs, screenshots, CAD drawings or evidence of a physical test.

External images are embedded directly from their original hosts, with a source caption next to each use:

- **peterxian / Home Assistant Community:** ZAC93 underside wiring photograph (`803c7819…jpeg`) and ESP32 wiring photograph (`8cff37fc…jpeg`), from the original 2023 build above.
- **Zooz / The Smartest House:** ZAC93 product photo (`image-20230425121602-1.png`), from the Zooz FAQ.
- **TubesZB:** `zwave-js-serial-config.png` and `zwave-setup-1.png`, `zwave-setup-2.png`, `zwave-setup-3.png`, from the setup guide above.

The Serial Port screenshot contains a legacy TCP address; the text expressly replaces it with the native encrypted ESPHome URL. The HA URL screenshot contains a sample localhost address; the text explains how to select a reachable server address. These screenshots are not taken from the user's Home Assistant instance.
